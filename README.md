## Sobre

Desenvolvedor Fullstack com experiência prática **desde a modelagem de dados e o desenvolvimento de APIs REST até a interface final**, com deploy automatizado e sustentação em produção. Minha base é a modelagem relacional (PostgreSQL/MySQL) e o ecossistema Node.js/TypeScript, integrando o fluxo a interfaces com Next.js e React Native. Trabalho principalmente com essa stack, mas já atuei com C#/.NET e PHP conforme a demanda dos projetos.

Em ambiente corporativo, atuo na sustentação e evolução de sistemas ativos. Entre as atividades, adaptei endpoints de API em C#/.NET e interfaces de usuário para integrar regras cadastrais (suporte a CNPJ alfanumérico) e mantenho um produto SaaS construído em PHP.

Conduzo o ciclo de entrega com Docker e rotinas de CI/CD via GitHub Actions.

Estudante de Ciência da Computação no **Instituto Mauá de Tecnologia (IMT)**.
